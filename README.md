# 刷题模拟器

科目化自测刷题工具（纯前端，单页应用）。内置两个科目：

- **Servlet 第3章**：核心 33 题 + 28 变式（学习通小测）
- **计组期末 · 真题单选**：8 套期末卷单选去重 64 题 + 12 道换数变式，每题带考点标签、解析与出处；全真模拟抽 20 题 / 12 分钟
- **数据结构 · 学习通作业**：绪论 27 题 + 第1章随堂 13 题 + 线性表 44 题 = 84 题（每次作业一个板块，可选板块刷题）；全真模拟抽 20 题 / 25 分钟

## 功能
- 全真模拟：33 题 / 8 分钟总计时，到时强制收卷
- 单题计时 / 练习模式 / 变式专练（61 题全覆盖）
- 错题本自动记录，可只刷错题
- 支持 PWA 安装：装到手机桌面或电脑桌面，离线可用

## 安装为应用
- 手机：浏览器打开页面 → 菜单 →「安装应用 / 添加到主屏幕」
- 电脑（Edge/Chrome）：地址栏右侧安装图标 → 桌面生成独立窗口应用

## 本地使用
直接下载 `index.html` 双击打开即可（无需联网）。
