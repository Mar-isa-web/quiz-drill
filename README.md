# 刷题模拟器

科目化自测刷题工具（纯前端，单页应用，PWA 离线可用）。内置五个科目：

- **Servlet 第3章**：核心 33 题 + 28 变式（学习通小测）
- **计组期末 · 真题单选**：8 套期末卷单选去重 116 题 + 12 道换数变式，每题带考点标签、解析与出处
- **数据库原理与应用**：单元测试一 46 题单选 + 2 道多选改编变式（学习通）
- **数据结构 · 学习通作业**：绪论 27 + 第1章随堂 13 + 线性表 44 + 栈和队列 25 = **109 题**，按作业分板块，可分板块刷也可整科连刷
- **马克思主义基本原理**：导论 17 + 第一章 33 = **50 题**（学习通章节测验，满分题库），每题带考点标签与解析，按章节分板块

## 功能
- 全真模拟：各科目独立题数与时长（Servlet 33 题 / 8 分钟、计组抽 20 题 / 12 分钟、数据库 46 题 / 15 分钟、数据结构抽 20 题 / 25 分钟、马原抽 20 题 / 12 分钟），到时强制收卷
- 单题计时快刷 / 练习模式 / 变式专练 / 背题速览 / 战况统计
- 错题本自动记录，可只刷错题
- 深色主题；支持 PWA 安装到手机桌面或电脑桌面，离线可用

## 安装为应用
- 手机：浏览器打开页面 → 菜单 →「安装应用 / 添加到主屏幕」；已装旧版的话，打开后刷新一两次即自动升级到新版
- 电脑（Edge/Chrome）：地址栏右侧安装图标 → 桌面生成独立窗口应用

## 本地使用
直接下载 `index.html` 双击打开即可（无需联网）。
